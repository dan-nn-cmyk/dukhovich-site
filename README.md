# Dukhovich — сайт-лендинг (текущее состояние)

Одностраничный лендинг для бренда **Dukhovich** (кастомные рюкзаки для аутдора и парапланеризма). Собран как статический HTML без сборки/фреймворка.

## Как открыть

Просто открой `index.html` в любом браузере — двойным кликом или через «Открыть в браузере». Файл полностью самодостаточный: шрифты и все фотографии уже встроены внутрь (base64), никаких внешних файлов для показа страницы не требуется. Это сделано намеренно — при пересылке одним файлом (мессенджер, почта) ничего не отвалится и не потеряется.

Для локальной разработки удобнее поднять любой статический сервер в папке (чтобы работали относительные пути, если будешь их добавлять):

```
python -m http.server 8000
```

и открыть `http://localhost:8000/index.html`.

## Структура архива

```
index.html            — сам сайт, единый файл, ничего не подключает извне
assets/img/            — ИСХОДНИКИ фотографий и логотипа (то, что было встроено в html base64-ом).
                          Не требуются для показа сайта — нужны только если будешь менять картинки.
assets/fonts/           — служебные файлы сборки шрифтов (см. ниже "Шрифты")
sources/                — оригиналы материалов, присланных для работы над сайтом:
  logo-style-series.pdf — подборка вариантов стиля логотипа (от неё выбран стиль "Topographic Series")
  positioning.docx       — документ с позиционированием бренда Dukhovich
  Logo.svg               — официальный векторный логотип Dukhovich (сейчас встроен в сайт inline-SVG)
```

## Что уже сделано

1. **Визуальный стиль** выбран по референсам из `logo-style-series.pdf` — серия "Topographic Series" (тёмный фон, топографические линии рельефа, координаты/высоты как декоративный элемент).
2. **Дизайн-редизайн** в духе премиальных outdoor-брендов: пилюлеобразные кнопки, крупные скругления карточек, реальная фотография (подобрана на Unsplash, лицензия Unsplash License — свободна для коммерческого использования) вместо плоских иконок, кастомные шрифты.
3. **Ребрендинг** с рабочего плейсхолдера "ULITKA" на настоящий бренд **Dukhovich** — подставлен присланный векторный логотип (`sources/Logo.svg`), перекрашен в терракотовый акцент сайта (`#c17a4a`), встроен как inline SVG (не растровая картинка — острый на любом размере, легко перекрашивается).
4. **Текст выровнен по позиционированию** из `positioning.docx` — без слепого копирования, но с поправкой смысловых акцентов там, где старый текст ему противоречил: убран уклон в "нести с собой больше/тяжелее", усилена идея "свобода = меньше лишнего", архетип Исследователь+Мудрец (спокойный, компетентный голос, без геройского пафоса).
5. Починены баги вёрстки: наложение кнопки на название бренда в мобильной шапке, несимметричные отступы у разделителей в блоке статистики на hero, критичный баг с анимацией появления секций (могла оставлять контент невидимым — теперь контент всегда виден по умолчанию, анимация — необязательное улучшение поверх).

## Важно проверить перед публикацией

- **Модели и цены в каталоге — заглушки.** Текущий сайт заточен под парапланерный угол (CONTOUR 35 / SUMMIT 55 / GLIDER 75 PRO / EXPEDITION 90, цены в ₸). В `positioning.docx` реальный продукт Dukhovich описан скорее как **ультралайт-снаряжение для треккинга** (упоминаются модели "Alpinist 45", "Alpinist 50"). Нужно решить: адаптировать копирайт/каталог под реальную линейку, или парапланерное позиционирование — осознанный отдельный угол бренда. Сейчас это не согласовано.
- **Контакты — заглушки**: телефон, e-mail (`hello@dukhovich.gear`), адрес мастерской в Алматы — придуманы для демонстрации, нужно заменить на настоящие.
- Координаты/высоты на патчах и в тексте (43.2389°N 76.8897°E, 3426 м и т.д.) — декоративные, для стиля "Topographic Series", не проверены как реальные данные.

## Шрифты

Используются: **Unbounded** (заголовки/логотип), **Golos Text** (основной текст), **JetBrains Mono** (координаты/цифры). Все три подключены как `@font-face` с шрифтами, закодированными в base64, прямо в `<style>` внутри `index.html` (см. начало файла). `assets/fonts/embedded-fonts.css` — это тот же самый блок отдельным файлом (на случай, если понадобится переиспользовать шрифты в другом проекте); `assets/fonts/fonts.css` — черновая ссылка на исходный Google Fonts CSS, из которого всё собиралось. Ни один из файлов в `assets/fonts/` не обязателен для работы `index.html`.

## Изображения

Все 16 фотографий (герой, карточки товаров, фактуры кастомизации, фото пилотов) — в `assets/img/`, взяты с Unsplash (свободная лицензия). Логотип (`logo-mark*.png`, `logo-square*.png`) больше не используется как картинка — заменён на inline SVG прямо в разметке `index.html`, эти файлы оставлены в архиве только как референс/бэкап.

Если нужно заменить фото: найди нужный файл в `assets/img/`, замени его новым (тем же именем), затем перекодируй в base64 и вставь в `index.html` в соответствующий `src="data:image/jpeg;base64,..."` — либо просто временно верни сайту внешние ссылки (`src="assets/img/имя-файла.jpg"`) для локальной разработки и встрой обратно перед финальной отправкой.

## Технологии на странице

Ванильный HTML/CSS/JS, без фреймворков и сборки. Из примечательного:
- Canvas-анимация топографических линий на hero (`.topo-canvas`, JS внизу файла).
- Вся интерактивность (мобильное меню, форма заявки, анимация появления) обёрнута в try/catch — сбой одного блока не должен ронять остальное.
- Форма заявки в контактах не отправляет данные никуда (нет бэкенда) — просто показывает сообщение об успехе. Нужно подключить реальную обработку (email/CRM/форма-сервис) перед продакшеном.
